# Работа с проектом

Сначала прочитайте `PROJECT_STATE.md`: это краткая актуальная сводка вместо истории переписки и старых ТЗ. Пользователь общается на русском.

Рабочая папка — `E:\AA\Расписание процедур`. Приложение для Windows, итоговый продукт — PNG. Текущая работа — автоматическое заполнение: правила описаны в `PROJECT_STATE.md`.

Не меняйте существующие пользовательские расписания ради проверок. Для оконных проверок задавайте отдельную папку `RITM_SMOKE_DIR` внутри `artifacts/` и используйте `--smoke-test`.

Перед изменениями проверяйте `git status` и сохраняйте незакоммиченные правки. Обновляйте сводку при существенном изменении поведения или архитектуры; не накапливайте в ней историю каждого шага.
